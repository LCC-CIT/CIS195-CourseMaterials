# Project Instructions for AI Assistants (CIS 195 Course Materials)

## Repository Overview
This repository contains the course materials, lecture notes, lab instructions, and grading rubrics for **CIS 195: Web Authoring 1 (HTML & CSS)** at Lane Community College.

---

## Core Guidelines & Conventions

### 1. Source of Truth for Schedule & Labs
- The primary source of truth for the current course schedule, lab numbering, and assignment topics is [`docs/CIS195_Syllabus.md`](docs/CIS195_Syllabus.md) (and [`docs/CIS195_Syllabus_Online.md`](docs/CIS195_Syllabus_Online.md)).
- When updating or creating lab materials, always align with the syllabus numbering (Labs 1 through 9).

### 2. Lab Directory and File Naming
- **Lab Folders**: Use two-digit zero-padded numbers: `Lab01`, `Lab02`, ..., `Lab09` (inside `docs/Labs/` and `LabStarters/`).
- **Instruction Files**: Name primary markdown instructions as `Lab<N>Instructions.md` (e.g., `Lab6Instructions.md`, `Lab9Instructions.md`).
- **Rubrics**: Name standard rubrics as `Lab<N>Rubric-CIS195.*` (e.g., `.htm`, `.xlsx`, `.xlsm`).

### 3. File & Link Integrity
- Preserve existing document formatting, headers, and creative commons copyright notices at the bottom of markdown instruction files.
- When moving or renaming lab files, ensure relative links to rubrics, example assets (PDFs, images), and lecture notes are updated accordingly.
