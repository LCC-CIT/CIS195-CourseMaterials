By the end of this week, you will be able to:

-   Explain the history and purpose of HTML.
-   Review the use of basic formatting elements like &lt;string&gt; or &lt;ul&gt;.
-   Use HTML structural elements like &lt;section&gt; or &lt;article&gt;.
-   Use the &lt;blockquote&gt; and &lt;cite&gt; elements.
-   Use special characters like ♥.
-   Understand the difference between in-line and block elements.
-   Apply an external style sheet (CSS file).
