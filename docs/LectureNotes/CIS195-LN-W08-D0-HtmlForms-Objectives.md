## Overview

You will learn how to add a form to your web page so that someone can open your page in a browser and enter information. Ultimately, that information will be processed either by JavaScript running in your web page (you’ll learn how to do this in CS133JS) or by code running on a server (you’ll learn to do that in CS295N). For now you will just learn to create HTML forms&mdash;without the processing code.
