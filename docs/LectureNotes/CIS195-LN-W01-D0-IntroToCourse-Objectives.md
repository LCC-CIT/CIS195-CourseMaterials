## Overview

This week you will be introduced to the World Wide Web and the basics of creating web pages with HTML!

## Learning Objectives

This week you will learn how to create web pages using HTML <span style="font-style: italic;">elements</span> for:

- Headings
- Text formatting (bold, italic, etc.)
- Line breaks
- Unordered and ordered lists
- Links
- Images
